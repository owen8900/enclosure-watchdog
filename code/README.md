# code

算法层与验证用例。分两块：

`App/` 是硬件无关的逻辑层，只依赖 `stdint.h` 和标准数学库。
上板时把这个目录整个拷进 STM32 工程即可，代码不用改。
硬件相关的部分用函数指针注入（见 `heater.h` 的 `pwm_set_fn`）。

`pc_test/` 是 PC 端验证用例，用来在没有硬件的情况下验证逻辑正确性。

在仓库根目录执行：

```bash
make test
```

当前输出 `PASS = 11  FAIL = 0`。用例说明和实测数据见 `../docs/测试报告.md`。

需要注意：PC 端验证只能覆盖逻辑正确性。时序、噪声、采样误差、
总线竞争这些问题必须上板之后才能发现。
